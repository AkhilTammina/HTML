🌴 Vacation Website

A simple vacation website created using HTML5. This project is designed to practice the fundamentals of HTML, including page structure, links, images, tables, forms, and navigation between multiple webpages.

📌 Pages

- 🏠 Home — "index.html"
- 📞 Contact — "contact.html"
- 🕐 Hours — "hours.html"

🖼️ Images

The project also contains an "img" folder with the images used on the webpages.

🛠️ Technology Used

- HTML5

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run the file using Live Server or Live Preview.

🎯 Purpose

This project was created to practice HTML5 and learn how to build a simple multi-page website using HTML.
